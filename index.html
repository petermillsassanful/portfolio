// Project 01

Zenrixa

Where scroll becomes spectacle.

Overview

Zenrixa is a VR-themed website built as a flagship interaction piece. Scroll progress directly drives 3D scene transformations, camera movements, and ambient particle fields. No page transitions, every pixel of vertical scroll rewrites the visual state in real time.

The challenge was achieving cinematic motion without sacrificing performance: all animations run on the compositor thread via transform and opacity, with the Scroll-Driven Animations API providing the timeline. WebGL handles the volumetric environment.

My Role

Sole front-end architect and designer. Responsible for the WebGL scene graph, scroll-animation pipeline, performance budget, and the custom CSS-only design system.

Type VR / Interactive Website
Focus Scroll-Driven Animation
Status Complete

Stack

  • WebGL / Three.js
  • Scroll-Driven Animations API
  • GSAP
  • CSS 3D Transforms
  • Vanilla JS (ES2022)
  • CSS Custom Properties
  • HTML5 Canvas

// Project 02

Academic Hub

A full-stack LMS engineered across 10 deliberate sprints.

Overview

Academic Hub is a production-grade Learning Management System built across 10 structured phases. It handles dual user roles, lecturers and students, with automatic enrollment routing based on academic level and course prerequisites.

The system ships as a PWA with offline capability, push notifications, and a mobile-first layout. Supabase powers real-time data, row-level security, and auth, while Next.js 14's App Router handles nested layouts and server components for near-instant page loads.

My Role

Lead developer and architect. Designed the database schema, RLS policies, component hierarchy, and the overall developer workflow used to accelerate each phase build.

Type Full-Stack Web App / LMS
Phases 10 structured sprints
Status Complete

Stack

  • Next.js 14 (App Router)
  • Supabase (PostgreSQL + Auth)
  • TypeScript
  • PostgreSQL
  • PWA / Service Worker
  • Row-Level Security
  • Tailwind CSS

// Project 03

Melody

Luxury editorial portfolio for modern runway and campaigns.

Overview

Melody is a premium, minimal editorial portfolio website showcasing an emerging fashion model based in Accra, Ghana. The site presents collections of high-fashion editorial portraits, runway confirmation sheets, and brand campaigns. Designed with sophisticated editorial typography, luxurious negative space, and smooth, immersive transitions that mirror high-end fashion print magazines.

The challenge was delivering a media-heavy gallery website that loads near-instantly on mobile devices. This was achieved using Vite for lightning-fast bundling, asset loading pipelines for responsive imagery, and hardware-accelerated layouts to support high-fidelity visuals.

My Role

Sole front-end developer and designer. Crafted the typography system, grid portfolios, and responsive layout interfaces that ensure standard layout consistency across different mobile and desktop device sizes.

// Project 04

V2 Herbal Care

Traditional medicine meets modern medical clinic accessibility.

Overview

V2 Herbal Care Clinic is a specialized medical center based in Weija Gbawe, Ghana, offering holistic healthcare with focused regimens in naturopathy, stroke care, and general wellbeing. The website acts as a modern, accessible interface for patients seeking natural treatment plans, scheduling virtual or physical clinic check-ups, and learning about herbal treatment catalogs.

The challenge was building an authoritative, clean, and clinical experience that bridges the gap between natural herbal therapies and professional clinical standards. This was implemented with semantic layouts, clean grids, appointment request modules, and optimized assets to ensure fast, reliable loads across regions in Ghana with varied network conditions.

My Role

Full-stack developer and designer. Responsible for mapping the content structure, clinic hours representation, service catalogs, responsive form integrations, and hosting configuration.

Type Medical & Clinic Website
Location Weija Gbawe Municipal, Ghana
Status Live
